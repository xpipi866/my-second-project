# 智能鱼缸监控终端 — 嵌入式软件

基于**正点原子 F429（STM32F429）** 的智能鱼缸控制系统，负责传感器采集、本地显示、触控交互、继电器控制及 WiFi 数据上云。


## 📌 项目简介

本项目是 IoT 水生态监测系统的**嵌入式端软件**，运行于正点原子 F429 开发板。主要功能包括：

- 采集**水温、水质（TDS 电压）、鱼缸水位、补水箱水位、鱼粮余量**共 5 项环境指标
- 在 **LCD 触摸屏**上实时显示监测数据和设备状态
- 支持触控交互：调节目标温度、切换过滤/增氧/喂食模式、手动喂食
- 自动控制：**加热、过滤、增氧、补水泵、喂食机**共 5 路继电器
- 通过 **ESP8266（串口3）** 连接 WiFi，将数据上报至**巴法云**平台


## 🛠️ 硬件平台

| 组件 | 型号/说明 |
|:---|:---|
| 主控 | STM32F429IGT6（正点原子 F429 核心板） |
| 屏幕 | 4.3 寸 RGB LCD（LTDC 驱动） |
| 触摸 | 电阻式触摸屏（SPI 接口） |
| 温度传感器 | DS18B20（单总线） |
| 水位传感器 | 3 路浮球开关（高水位、低水位、补水箱水位） |
| 鱼粮检测 | 光电/微动开关（余量检测） |
| 水质检测 | 模拟电压采集（ADC） |
| 继电器 | 5 路（加热、过滤、增氧、喂食机、补水泵） |
| WiFi 模块 | ESP8266（USART3） |
| EEPROM | AT24C02（参数掉电保存） |
| RTC | 内置 RTC |


## 🎯 核心功能

### 传感器采集
- **水温**：DS18B20 采集，精度 0.1℃
- **水质**：ADC 采集电压，映射为 0~100% 纯度
- **水位**：3 路浮球开关（鱼缸低位、鱼缸高位、补水箱水位）
- **鱼粮**：余量检测（充足/不足）

### 自动控制逻辑

| 设备 | 控制逻辑 |
|:---|:---|
| 加热棒 | 水温 < 目标温度 且 鱼缸有水时开启 |
| 过滤器 | 手动开/关，或自动模式（每小时运行 N 分钟） |
| 增氧泵 | 手动开/关，或自动模式（每 N 秒运行 N 秒） |
| 喂食机 | 手动投食，或自动模式（每 12/24 小时投食一次） |
| 补水泵 | 低水位触发 + 补水箱有水 + 高水位未触发时开启；高水位触发或补水箱缺水时关闭 |

### LCD 触控交互
- 实时监控页：显示所有传感器数据与设备状态
- 设备控制页：切换工作模式、调节温度、手动喂食
- 日志查看：滚动显示系统运行日志（最多 300 条）

### WiFi 数据上云
- 通过串口 3 与 ESP8266 通信
- TCP 连接巴法云（bemfa.com:8344）
- 每约 3 秒上报一次 JSON 格式数据


## 🚀 快速开始

### 环境准备
- IDE：Keil MDK 5
- 芯片支持包：STM32F4xx_DFP
- 调试器：ST-Link / J-Link

### 编译与烧录
1. 使用 Keil 打开项目工程文件
2. 选择芯片型号：STM32F429IGTx
3. 编译（F7）
4. 烧录（F8）

### 配置 WiFi
在 `main.c` 开头修改以下宏定义：

```c
#define WIFI_SSID     "你的WiFi名称"
#define WIFI_PWD      "你的WiFi密码"
#define BEMFA_UID     "你的巴法云UID"
#define BEMFA_TOPIC   "你的主题名称"
```

### 上报数据格式

上报数据示例：

```json
{"temp":"26.5","water":"0","food":"0"}
```

| 字段 | 说明 |
|:---|:---|
| `temp` | 水温（℃） |
| `water` | 补水箱状态（0=有水，1=缺水） |
| `food` | 鱼粮状态（0=充足，1=不足） |
